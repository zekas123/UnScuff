UnScuff
An app that helps you optimize your work time and stop getting distracted by things that don't matter.

Features
Tasks with counters – Add a task and set how many times you need to complete it.

Timer mode – Set a task and the time allowed for it, hit "Start" – the timer begins.

Annoying reminders – Every 2 hours, the app reminds you it exists. No more "just one more game."

Auto-start – UnScuff launches with your system. You can't forget to open it.

Hard to close – Closing the app isn't easy. It will keep reminding you to get back to work.


How to use
Add a task.

Choose a mode:

by number of completions

by time (timer)

Click Start – the countdown begins.

When you finish a task, mark it as done.

Don't try to close or ignore the app. UnScuff will remind you itself.

Why this exists

Because sometimes you need a digital babysitter that won't let you slack off. UnScuff is here to annoy you just enough to stay productive.


How to run
Open the folder:

text
UnScuff\UnScuff\bin\Debug\net10.0-windows\
Double-click UnScuff.exe

If Windows warns you, click "More info" → "Run anyway"

That's it.

Or run from Visual Studio
Open UnScuff.sln

Press F5

**To delete a task:**  
Open the corresponding `.txt` file and remove the line manually. Then restart the app.
